How it works / 工作方式

多一层观察，
少一份盲目。

它不是代理服务，而是放在已有本机代理之前的连接网关。只有实际接入的连接，才在它的观察范围内。

01 /

接入本机网关

让经过配置的 Claude Desktop 或本地 Claude Code 连接指向本机入口，再由已有代理转发。

02 /

核验出口与配置

检查预期出口、检测结果和配置基线。网络短暂波动时进入观察窗口，避免一次探测失败就立即中断。

03 /

异常时保护性阻断

出口明确变化、配置异常或持续无法验证时，守护会阻断已接入连接；恢复仍需重新核验。

Know the limits / 使用边界

安全感，来自
知道边界在哪里。

这是一个开源的连接守护实验项目。了解它能覆盖什么，和了解它不能覆盖什么，同样重要。

  • 01不能保证账号不被封禁，也不能判断账号资格或平台政策。
  • 02仅覆盖实际接入的本机连接；外部浏览器、远程任务及未接管流量需要分别验证。
  • 03不代表所有 DNS 或 UDP 流量均受到保护。探测存在时间窗口，不是零延迟防火墙。
  • 04当前提供源码和隔离测试，并非通用安装包；需要自行配置代理和适配环境。
